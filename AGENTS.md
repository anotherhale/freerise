# Project Instructions

## Project identity and ownership
- This repository represents one independent Roblox game: **Olympic Slope** (repository: FREERISE).
- The creator owns the game's creative direction and approves its requirements.
- Approved project documents are the source of truth.
- Do not import lore, design, code, assets, architecture, or backlog from unrelated projects or showcase repositories.

## Working rules
- Inspect the repository and relevant documents before modifying anything.
- Preserve existing creator work and keep changes scoped to the requested task.
- Prefer feature branches and pull requests; do not bypass branch protection or rewrite history.
- Never commit credentials, tokens, private keys, or other secrets.
- Never claim a test passed unless it was run and its result observed.
- Ask before destructive operations, publishing, production changes, or consequential external actions.
- Record significant design and architecture decisions.
- Do not silently change approved requirements.
